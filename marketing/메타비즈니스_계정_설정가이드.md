# 메타 비즈니스 계정 설정 가이드 — 프라임치과(경주)

> 계정 생성은 원장님 본인 페이스북 로그인 + 본인/사업자 인증이 필요해서 직접 진행하셔야 합니다.
> 아래 순서대로 하시면 30분 안팎이면 끝납니다. (Meta 화면 명칭은 수시로 바뀌니 비슷한 메뉴를 찾으시면 됩니다.)

---

## 0. 미리 준비할 것
- [ ] 원장님 **개인 페이스북 계정** (실명, 2단계 인증 켜두기 — 광고계정 정지 예방)
- [ ] **병원 공식 이메일** (예: 병원 전용 Gmail. 개인 메일과 분리 권장)
- [ ] **사업자등록증** PDF/사진 (비즈니스 인증용)
- [ ] 병원 대표 전화번호, 도로명 주소, 홈페이지 주소
- [ ] 로고(정사각형 1080×1080), 커버 이미지(1640×624 권장) — `images/` 폴더 활용
- [ ] 결제용 **법인/사업자 카드**

## 1. 페이스북 페이지 만들기 (없을 경우)
1. facebook.com → 메뉴 → **페이지** → **새 페이지 만들기**
2. 페이지 이름: `프라임치과 경주` (검색되기 쉬운 이름)
3. 카테고리: **치과** (Dentist & Dental Office)
4. 주소·전화·진료시간·홈페이지 입력, 로고/커버 업로드

## 2. 인스타그램을 프로페셔널 계정으로 전환
1. 인스타그램 앱 → 설정 → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → **비즈니스**
2. 카테고리: 치과
3. 위에서 만든 페이스북 페이지와 연결

## 3. 비즈니스 포트폴리오(구 비즈니스 관리자) 만들기
1. **business.facebook.com** 접속 → 개인 페이스북으로 로그인
2. **비즈니스 포트폴리오 만들기** 클릭
3. 입력값
   - 비즈니스 이름: 사업자등록증상 상호와 **동일하게** (인증 시 대조함)
   - 이름 / 비즈니스 이메일: 병원 공식 메일
4. 이메일 인증 메일 확인

## 4. 자산 연결 (비즈니스 설정 → 계정)
| 항목 | 메뉴 | 비고 |
|---|---|---|
| 페이스북 페이지 | 계정 → 페이지 → 추가 | 1단계 페이지 |
| 인스타그램 | 계정 → Instagram 계정 → 추가 | 2단계 계정 |
| 광고 계정 | 계정 → 광고 계정 → **새 광고 계정 만들기** | 시간대 **서울(GMT+9)**, 통화 **KRW** — 나중에 변경 불가! |
| 픽셀/데이터세트 | 데이터 소스 → 데이터 세트 | 홈페이지 예약·전화 클릭 전환 추적용 |
| 결제 수단 | 결제 → 결제 수단 추가 | 사업자 카드 |

## 5. 비즈니스 인증 (보안 센터)
- 비즈니스 설정 → **보안 센터** → **인증 시작**
- 사업자등록증 업로드, 주소·전화번호 일치 확인
- 인증되면 광고 한도↑, 계정 정지 위험↓

## 6. 직원/대행사 권한
- 사용자 → 사람 → 추가: 실장님 등은 **부분 액세스(콘텐츠 / 광고 관리)** 만
- 마케팅 대행사는 **파트너**로 추가 (비밀번호 공유 금지)
- **관리자(전체 권한)는 원장님 포함 최소 2명** 지정 — 한 명 계정이 막혀도 복구 가능

## ⚠️ 치과 광고 전 꼭 확인할 것

### 의료광고 사전심의 (의료법 제56·57조)
- 인스타그램·페이스북은 **일일 평균 이용자 10만 명 이상 매체 → 의료광고 사전심의 대상**
- 유료 광고 집행 전 **대한치과의사협회 의료광고심의위원회** 심의 필수, 심의번호 표기
- 금지 사례: 치료 전후 사진 단독 게재, "최고·유일·100%", 환자 후기·체험담, 과도한 할인·이벤트 가격 강조, 비급여 가격 할인 유인 등

### Meta 광고 정책
- 건강 관련 광고는 **개인의 건강 상태를 단정하는 문구 금지**
  - ❌ "잇몸에서 피가 나시나요?" "당신의 틀니가 불편하죠?"
  - ✅ "잇몸 건강, 정기검진으로 확인하세요"
- 신체 비포/애프터 이미지 금지
- 민감 정보(건강 상태) 기반 상세 타겟팅 제한 → **지역(경주 반경) + 연령** 위주로 타겟팅
